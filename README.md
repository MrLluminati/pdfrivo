# PDFRivo

Free, browser-based PDF and image utilities.

> **Status:** Project initialized. The first functional release is being developed on a feature branch.

## Principles

- **Free access:** no accounts, watermarks, or artificial daily quotas.
- **Privacy-first:** process supported files locally in the browser, without uploading them.
- **Honest capabilities:** do not advertise lossless or effective PDF compression, OCR, or secure redaction until those tools are properly implemented and tested.
- **Accessible and responsive:** support keyboard navigation and mobile devices.
- **Gradual expansion:** publish tested tools instead of placeholder features.

## Planned deployment

- **Source:** this GitHub repository
- **Hosting:** Cloudflare Pages (public site)
- **Domain:** `pdfrivo.com` (planned; not deployed)
- **Monetization:** optional ads and donations, with privacy and consent compliance before activation.

## Development

See the first feature pull request for the working website, tools, and local setup instructions.

## Security

Do not submit sensitive files to online services during development. This project intends to process files in the browser; future server-side functionality must be prominently disclosed and opt-in.
